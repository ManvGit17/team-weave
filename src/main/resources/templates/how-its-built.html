Architecture, enforced

These rules run as tests on every build; breaking one fails it.

  • Layers: web → application → domain; infrastructure is reachable only from application.
  • The domain is framework-free: no Spring, and no dependency on the outer layers.
  • Each pattern lives in its package: strategies in matching, constraints in constraint, commands in command, states in team.
  • The class diagram below is generated from the compiled code; the build fails if the committed copy is stale.
